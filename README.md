# First Unity Project

A small 3D Unity project created to learn the fundamentals of Unity and basic game development.

## Features

- Third-person player movement
- Camera-relative WASD controls
- Mouse-controlled horizontal camera rotation
- Rigidbody-based physics and collision
- Collectible coin system
- Score tracking
- Pickup sound effect
- Win screen with restart button
- Basic materials, textures, lighting, and prefabs

## Controls

- **WASD** — Move
- **Mouse** — Rotate camera horizontally

## Future Work

- Add Idle and Walk animations to the player character
- Add more sound effects
- Improve the environment and level design
- Add visual effects when collecting items
- Improve UI and game menus

## Built With

- Unity 6
- C#
- Universal Render Pipeline (URP)

This project was created as a first step toward learning Unity and game development.
